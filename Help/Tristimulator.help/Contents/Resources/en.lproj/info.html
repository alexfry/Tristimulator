Check image information and HDR

Use the info bar

The info bar shows the image’s pixel size, channel count, bit depth, and OpenColorIO source colour space. Depending on the file, it also shows:

  • The maximum luminance, when the file includes it

  • An AMF button, when an ACES Metadata File is attached

  • A layer menu, when an OpenEXR file has more than one layer

For a still, the info bar fades after about 3 seconds without pointer movement. Move the pointer to show it again.

Check HDR for the display

The sun button in the toolbar reads HDR or SDR for the current display. Click it to see extended dynamic range (EDR) details, including a peak measurement of the image on screen.
