Change the default colour settings

Choose the default config

  1. Choose Tristimulator > Settings (or press Command-Comma), then click OCIO.

  2. Choose the built-in config, the config in the OCIO environment variable, or a custom config file.

The default applies to images you open afterward.

Save, load, or reset a window’s colour settings

Use the OCIO menu:

  • Export Settings: Saves the window’s colour pipeline to a JSON file.

  • Import Settings: Loads a JSON file you exported earlier.

  • Revert to Built-in Config: Switches the window back to the built-in config and resets the pipeline.

  • Reveal Settings File in Finder: Shows color-settings.json in the Finder.
