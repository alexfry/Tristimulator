Open images, sequences, and movies

Each image, sequence, or movie you open gets its own window.

Open a file

  • In Tristimulator, choose File > Open, select a file, then click Open.

  • In the Finder, open the file with Tristimulator.

If Tristimulator can’t read a file, it shows an error and the window stays empty.

Open an image sequence

Open any frame of the sequence. Tristimulator opens a still whose name ends in digits as a sequence when other files in the same folder share its name prefix and extension.

For example, opening shot_0001.exr plays it with shot_0002.exr and the rest of that run. A numbered file with no matching files opens as a single still.

Open another window for the same file

Choose File > New Window for This Image (or press Option-Command-N). The new window has its own OpenColorIO settings, so you can compare two colour pipelines side by side.

Attach an ACES Metadata File (AMF)

When you open an image, Tristimulator looks in the same folder for an .amf file with the same name, the same name without the frame number, or the only .amf file in that folder.

To choose an AMF yourself, choose File > Load AMF, then select the file.

When an AMF is attached, the info bar shows an AMF button, and the colour pipeline offers the input, looks, and output from the file.
