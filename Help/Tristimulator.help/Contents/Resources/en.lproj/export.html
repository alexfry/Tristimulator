Copy or export an image

Copied and exported images include the window’s OpenColorIO processing.

Copy an image

  • With an HDR gain map: Choose Edit > Copy Image (or press Command-C).

  • As a TIFF in the screen colour space: Choose Edit > Copy Image (Native Colorspace) (or press Shift-Command-C).

Export an HDR image

  1. Choose File > Export Gain Map Image (or press Shift-Command-E).

  2. Choose a name and location. To save a JPEG, give the file a .jpg or .jpeg extension; otherwise Tristimulator saves a HEIC file.

  3. To make the file show as HDR in Chrome and Android apps, select UltraHDR Compatible (Chrome / Android).

  4. Click Save.

The exported file includes an HDR gain map.
