File formats Tristimulator can open

Tristimulator reads stills with OpenImageIO and movies with AVFoundation.

Film and HDR stills

  • OpenEXR (.exr), including multilayer files

  • DPX (.dpx)

  • Cineon (.cin)

  • Radiance HDR (.hdr, .hdri, .rgbe, .xyze)

  • IFF (.iff, .z)

  • RLA (.rla)

  • Softimage PIC (.pic)

If an OpenEXR file has more than one layer, use the layer menu in the info bar to choose the layer you see.

Common stills and textures

  • PNG, JPEG, TIFF, BMP, GIF, WebP, HEIC, and HEIF

  • Photoshop, Targa, SGI, ICO, JPEG 2000, and JPEG XL (.jxl)

  • TIFF textures (.tx, .env, .sm, .vsm)

  • DirectDraw Surface (.dds)

  • Portable bitmaps (PBM, PPM, PGM, PNM) and Portable Float Map (.pfm)

Scientific images

  • FITS (.fits, .fit, .fts)

  • DICOM (.dcm, .dicom)

Movies

QuickTime (.mov) and MPEG-4 (.mp4, .m4v) files open from the Finder. Tristimulator also treats .avi, .mkv, .mxf, and .dv files as movies, and can open other files that macOS identifies as movies.
