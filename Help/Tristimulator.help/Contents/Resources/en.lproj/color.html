Set up colour with OpenColorIO

Each window has its own colour pipeline.

  1. Click the OpenColorIO button at the right end of the toolbar.

    The colour pipeline opens in a popover. In full screen, the button is on the floating toolbar.

  2. Set any of the following:

    • Config: The OpenColorIO config. Browse for a file or reload the current path. A config inside the app is labelled “Built-in”, followed by the config name.

    • Source: The input colour space, or an inverse display and view that converts display-referred data back to scene data. Tristimulator tries to match the file’s colour metadata to a colour space in the config.

    • Working Space: The intermediate colour space.

    • Looks: Look transforms from an attached ACES Metadata File. This appears only when the AMF has looks.

    • Display: A display and view from the config, or ACES 2.0. ACES 2.0 sets limiting primaries and a peak in nits, and can follow the display’s current extended dynamic range headroom. This section also switches between the Metal GPU path and the OpenColorIO CPU reference. Video frames always use the GPU.

    • Screen: The Metal colour space used to show the image on the display.

Settings you choose in a window override the default config for that window.
