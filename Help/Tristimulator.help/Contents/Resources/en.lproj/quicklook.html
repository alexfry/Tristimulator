Preview images in the Finder with Quick Look

Tristimulator includes a Quick Look extension, so you can preview an OpenEXR file in the Finder without opening Tristimulator. The preview uses the ACES 2.0 output transform and shows HDR highlights on displays that support extended dynamic range (EDR).

Preview a file

  1. In the Finder, select an OpenEXR (.exr) file.

  2. Press the Space bar, or choose File > Quick Look.

  3. Press the Space bar again to close the preview.

The extension previews OpenEXR files only. Other formats, such as Radiance HDR, DPX, and TIFF, use the Quick Look previews built into macOS. The extension doesn’t make Finder icon thumbnails; those come from macOS.

How the preview handles colour

The preview uses a fixed pipeline. It doesn’t use your OpenColorIO config, the colour settings you saved for the image in Tristimulator, or an attached ACES Metadata File (AMF).

  1. The extension reads the file’s colorSpace attribute and converts the pixels to ACES2065-1. It recognises these names:

    • ACES2065-1: ACES2065-1, lin_ap0, Linear ACES, and ACES

    • ACEScg: ACEScg, lin_ap1, Linear ACEScg, and lin_ap1_scene

    • Linear Rec.709: Linear Rec.709, Linear Rec709, Linear sRGB, lin_rec709, lin_srgb, sRGB - Linear, Linear, and scene_linear

    • Linear P3-D65: Linear P3-D65, lin_p3d65, Linear Display P3, lin_displayp3, and Apple Display P3 Linear

    Names aren’t case-sensitive. If the file has no recognised name, the extension uses the file’s chromaticities attribute. If it has neither, it treats the pixels as linear Rec.709.

  2. It applies the ACES 2.0 output transform to linear P3-D65. The peak brightness is 100 nits multiplied by the display’s current EDR headroom, and is never less than 100 nits. The preview redraws when the headroom changes.

The preview shows the image at 0 stops exposure, with all colour channels and no alpha, on a black background. It shows the image that macOS decodes from the file, so you can’t choose an OpenEXR layer. To change exposure, channels, layers, or colour settings, open the file in Tristimulator.

If the preview doesn’t appear

  • Put Tristimulator in your Applications folder and open it once. macOS registers the Quick Look extension when the app is opened.

  • Make sure the extension is turned on. Choose Apple menu > System Settings, click General, click Login Items & Extensions, then make sure the Tristimulator extension is turned on under Quick Look.

  • Reset Quick Look. In Terminal, enter qlmanage -r and qlmanage -r cache, then try the preview again.

The preview needs a Mac that supports Metal.
